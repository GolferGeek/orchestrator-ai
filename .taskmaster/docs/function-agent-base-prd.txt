# Function Agent Base PRD

## Project Overview
Create a new function-based agent architecture that enables developers to write programmable agent logic in TypeScript instead of relying solely on LLM context processing. This represents an evolution from simple context-based agents to true programmatic agents that can execute custom business logic, make API calls, and implement complex workflows.

## Problem Statement
Current context-based agents are limited to LLM prompt engineering and cannot execute custom business logic, make external API calls, or implement complex multi-step workflows. Customers need real agents that can perform actual tasks, not just sophisticated chatbots.

## Goals
- Enable programmable agent development through agent-function.ts files
- Maintain compatibility with existing agent discovery and metadata systems
- Integrate LangGraph for complex agent workflows and state management
- Provide centralized LLM management through existing LLMService
- Support real agent capabilities: API integration, data processing, decision trees
- Preserve agent-context.md for UI cards and metadata while adding execution logic
- **Extreme Simplicity**: Keep agent-service.ts files minimal (10-20 lines max) by abstracting all complexity
- **Clean Architecture**: FunctionAgentBaseService hides all implementation details from agent developers

## Target Users
- Internal development team
- Client developers building custom agents
- Interns and contractors implementing agent functionality

## Core Requirements

### 1. Function Agent Base Service
- Create FunctionAgentBaseService class extending A2AAgentBaseService
- **Hide All Complexity**: Abstract function loading, execution, and error handling from agent developers
- Dynamically import and execute agent-function.ts files with zero configuration
- Pass structured parameters to agent functions automatically
- Return agent function results without LLM processing
- Handle errors and provide meaningful error responses
- Support both synchronous and asynchronous agent functions
- **Inheritance Chain**: A2AAgentBaseService → FunctionAgentBaseService → AgentService (minimal)

### 2. Agent Function Interface
- Define standardized interface for agent-function.ts exports
- Accept parameters: userMessage, sessionId, conversationHistory, currentUser, authToken
- Return structured response with content and optional metadata
- Support TypeScript for type safety and development experience
- Enable dependency injection for services (LLMService, external APIs, databases)

### 3. LangGraph Integration
- Install LangGraph and related LangChain dependencies
- Extend LLMService to provide LangGraph-compatible LLM instances
- Support multiple LLM providers: OpenAI, Anthropic, Ollama, Google
- Integrate LangSmith evaluation services into LLM instances
- Maintain centralized LLM configuration and monitoring

### 4. Agent Structure Enhancement
- Maintain agent-context.md for discovery and UI metadata
- Add agent-function.ts for execution logic
- Keep agent-service.ts extending FunctionAgentBaseService
- Ensure backward compatibility with context-based agents
- Support mixed agent types in the same system

### 5. Development Experience
- **Ultra-Simple Agent Creation**: New agents require only extending FunctionAgentBaseService
- **Zero Boilerplate**: Agent developers focus purely on business logic in agent-function.ts
- **Complete Abstraction**: FunctionAgentBaseService handles all infrastructure concerns
- Provide clear examples and templates for agent functions
- Enable easy testing and debugging of agent functions  
- Support hot reloading during development
- Provide TypeScript definitions and intellisense
- Create documentation and best practices guide
- **Developer Velocity**: From idea to working agent in minutes, not hours

## Technical Specifications

### Agent Function Interface
```typescript
export interface AgentFunctionParams {
  userMessage: string;
  sessionId?: string;
  conversationHistory?: Array<{
    role: 'user' | 'assistant';
    content: string;
    metadata?: any;
  }>;
  currentUser?: any;
  authToken?: string;
  llmService?: LLMService;
}

export interface AgentFunctionResponse {
  response: string;
  metadata?: {
    agentName?: string;
    processingTime?: number;
    toolsUsed?: string[];
    [key: string]: any;
  };
}

export interface AgentFunction {
  execute(params: AgentFunctionParams): Promise<AgentFunctionResponse>;
}
```

```typescript
// agents/actual/specialists/hr_assistant/agent-function.ts (SIMPLE LANGGRAPH)
export const execute = async (params: AgentFunctionParams) => {
  const llm = params.llmService.getLangGraphLLM('openai');
  
  // Simple LangGraph workflow - single LLM call with HR expertise
  const messages = [
    { 
      role: 'system', 
      content: 'You are an HR expert. Here is the user\'s prompt. Please respond like an HR expert would.' 
    },
    ...params.conversationHistory,
    { role: 'user', content: params.userMessage }
  ];
  
  const response = await llm.invoke(messages);
  
  return {
    response: response.content,
    metadata: { 
      agentName: 'HR Assistant', 
      type: 'hr_guidance',
      processingTime: Date.now() 
    }
  };
};
```
