## 1. Design ErrorBoundary Component Using errorCaptured Hook [pending]

### Details:
Implement the ErrorBoundary component to wrap potentially unstable child components and capture rendering or lifecycle errors. Ensure the component exposes error state and supports scoped slots for custom fallback UI.

### Details:
Define a Pinia store module for error state. Update the store from within ErrorBoundary when errors are captured, enabling centralized error tracking and cross-component communication.
