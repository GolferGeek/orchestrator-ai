# Validation Services

This directory will contain request/response validation components for the A2A framework.

## Planned Components

- `json-rpc-validator.service.ts` - JSON-RPC protocol validation
- `schema-validator.service.ts` - Schema-based validation service
- `pipes/` - NestJS validation pipes
- `schemas/` - JSON schemas for validation
- `dto/` - Data Transfer Objects with validation decorators

## Responsibilities

- JSON-RPC 2.0 protocol compliance validation
- Request payload validation
- Response format validation
- Schema enforcement for agent communications
- Input sanitization and security validation
