# API v2 - Generated TypeScript Code

This directory contains TypeScript code (e.g., interfaces, client libraries) automatically generated from the OpenAPI contracts located in `../../contracts/`.

## Purpose

To provide type-safe data structures and/or client stubs for TypeScript applications (like the NestJS v2 implementation) that interact with the A2A v2 protocol.

## Generation Process

This code should typically be generated using an OpenAPI code generation tool (e.g., `openapi-generator`, `openapi-typescript`). The specific tool and commands should be documented here or in a script within this project.

**Note:** Do not edit files in this directory manually, as they will be overwritten during the code generation process. Any changes should be made to the source OpenAPI contracts.
